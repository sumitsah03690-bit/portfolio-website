Secure Compiler IDE

Multi-Agent Hierarchical RL for Compiler Optimization

Features security-first policy gating with 30+ CWE checks, a GATv2 world model for predicting pass outcomes, and two local AI models for code review — all without sending code to the cloud.

Up to 10% speedup over LLVM -O3 on PolyBench
